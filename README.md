# Protein per Dollar: Grocery Store Value Analysis

🏆 **Best Visualization Award — DSC 106, UC San Diego**

An interactive data visualization analyzing how much protein consumers get per dollar at different grocery stores across different levels of food processing. This project was created for DSC 106 at UC San Diego and received the **Best Visualization Award** among 140+ students.

## Dataset

The project uses a dataset containing **26,250 food products** from **Target, Walmart, and Whole Foods**. Each product includes information such as price, protein, calories, macronutrients, food category, brand, and food-processing level.

Working with this large product dataset allowed me to compare the value of protein across thousands of real-world food products rather than relying on a small sample.

## Overview

As someone who takes fitness and meal budgeting seriously, I wanted to investigate which grocery stores provide the most protein for the money without relying entirely on lower-quality foods.

I compared Target, Walmart, and Whole Foods using protein per dollar as the primary metric while accounting for different levels of food processing.

The analysis found that Target and Walmart provide similar value, while Whole Foods generally provides less protein per dollar, including within higher-quality food categories.

## Methodology

- Cleaned the dataset and filtered unrealistic values and outliers
- Calculated **protein per dollar** by dividing protein content by price
- Grouped foods into four categories based on processing level
- Calculated median protein per dollar for each store within each processing category
- Used a line visualization to compare stores across food-processing categories
- Added annotations and visual brackets to highlight differences between stores
